# 🚀 Python & Deep Learning 28-Day Practical Journey

> **"Learning by doing."** —— 从零到一打通深度学习与计算机视觉实操链路的 28 天沉淀记录。

---

## 📌 项目简介 (Overview)

本项目记录了在 28 天高强度实操中，从 Python 基础进阶到端到端深度学习项目落地的全过程。
虽然期间神经网络的核心数学理论还未全程同步跟进，但通过**高密度的工程代码实操与 Debug 攻坚**，成功打通了从数据预处理、模型训练、权重固化到预测推理的完整链路。

---

## 📂 仓库目录结构 (Directory Structure)

```text
py learning/
│
├── data/                 # 数据集存放目录（如 MNIST 等）
├── runs/                 # 模型训练与推理输出目录（detect/predict）
├── stage1/               # 阶段一：Python 进阶与基础演练
├── stage2/               # 阶段二：进阶编程与脚本实战
├── stage3/               # 阶段三：神经网络与核心算法演练
├── stage4_B/             # 阶段四：项目实战与综合应用
│
├── mnist_model.pth       # 训练生成的模型权重文件
├── yolov8n.pt            # YOLOv8 预训练/运行权重
├── requirements.txt      # 项目依赖环境说明
└── todo.json             # 学习与任务追踪清单
